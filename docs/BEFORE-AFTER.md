## Content retained deliberately

The existing script, proposed metric definitions, three-person survey limitation, YouTube packaging exercise and academic context were stronger than generic rewrites. They remain. This is a visual and narrative consolidation with selective new content, not an attempt to rewrite sound evidence for novelty.

The public Radio Ready case retains the “finite practice session” observation and duplex printing lesson. These show a decision and a correction, which are more useful than a list of software features.

## Follow-up outside this change

The existing downloadable résumé is a valid PDF but its wording predates the site. The abandoned proof-first branch contains a base64 text file mislabeled as a PDF; that file is not imported. A replacement résumé should be supplied or revised separately before treating the résumé and website as fully aligned.

No employer outcome, subscriber-growth figure, new campaign result or learning improvement was invented to fill that gap.
